
# ByteBank – Smart Personal Finance & Expense Manager

## About the Project
ByteBank is a web-based personal finance management application designed to help users manage their income, expenses and monthly budgets.

## Features
- User Registration and Login
- Secure Password Hashing
- Dashboard
- Income Management
- Expense Management
- Income and Expense History
- Transaction Management
- Monthly Budget Management
- Financial Analytics

## Technologies Used
- Python
- Flask
- Flask-SQLAlchemy
- SQLite
- HTML
- CSS
- Bootstrap
- JavaScript
- Chart.js

## Installation and Setup

1. Clone the repository.
2. Create a virtual environment:
   python -m venv venv
3. Activate the environment:
   Windows: venv\Scripts\activate
4. Install dependencies:
   pip install -r requirements.txt
5. Run the application:
   python app.py
6. Open your browser:
   http://127.0.0.1:5000
